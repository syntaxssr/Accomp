- **Brand:** Accomp
- **Industry:** Outdoor Technology / Adventure Planning
- **Platform being promoted:** Mobile App (platforms not yet confirmed)
- **Website scope:** เว็บไซต์โปรโมตแอปเท่านั้น

## 2. Brand Essence

### Brand idea

**The trusted companion for every shared adventure.**

Accomp คือเพื่อนที่ช่วยให้ทุกคนในทริปเตรียมตัวพร้อม ตั้งแต่การวางแผน การแบ่งอุปกรณ์ การเก็บข้อมูลสำคัญ ไปจนถึงการใช้งานแผนที่แบบออฟไลน์

### Brand promise

ทำให้การออกผจญภัยร่วมกันเป็นเรื่องง่าย เป็นระเบียบ และมั่นใจได้ แม้ในจุดที่ไม่มีสัญญาณอินเทอร์เน็ต

### Brand philosophy

Adventure should never feel complicated.

ประสบการณ์กลางแจ้งที่น่าจดจำเริ่มจากการเตรียมตัวที่ดีและเพื่อนร่วมทางที่ไว้ใจกัน Accomp จึงรวมการวางแผน การแพ็กของ การทำงานร่วมกัน และการสำรวจไว้ในที่เดียว โดยผสานความสงบของธรรมชาติเข้ากับความเรียบง่ายของเทคโนโลยีสมัยใหม่

### Experience statement

Accomp should feel like the trusted friend who already planned the route, packed the essentials, shared the checklist, downloaded the offline map, and is ready to explore together.

## 3. Core Values

### Together

Outdoor adventures are better when shared.

### Preparation

Good planning creates better experiences.

### Simplicity

Powerful tools should remain effortless.

### Reliability

Essential features should work anywhere—even offline.

### Exploration

Every trail is an opportunity to discover something new.

## 5. Audience

### Primary audience

- Hiking enthusiasts
- Backpackers
- Campers
- Trekking groups
- Weekend adventurers
- National park visitors
- Travel companions
- Outdoor communities

### Age range

18–40

### Audience needs

- อยากวางแผนทริปร่วมกันโดยไม่ต้องกระจายข้อมูลหลายแอป
- อยากเห็นว่าใครรับผิดชอบอุปกรณ์ชิ้นใด
- อยากเก็บ itinerary, checklist และข้อมูลสำคัญไว้ในที่เดียว
- อยากใช้งานข้อมูลและแผนที่ได้แม้ไม่มีอินเทอร์เน็ต
- อยากลดความกังวลก่อนออกเดินทาง โดยไม่เพิ่มความซับซ้อน

## 6. Product Truths to Communicate

Accomp มีฟีเจอร์หลักหนึ่งเดียวคือ **Shared Trip Planning /
วางแผนทริปร่วมกัน** โดยมีสามความสามารถที่อยู่ภายในแผนทริปเดียวกัน:

1. Plan the trip / วางแผน
2. Prepare the gear / เตรียมอุปกรณ์
3. Ready offline / พร้อมใช้งานออฟไลน์

การเตรียมอุปกรณ์และความพร้อมออฟไลน์ไม่ใช่ top-level feature แยก แม้เว็บไซต์
จะแบ่งเป็นบทเพื่อช่วยเล่าเรื่องก็ตาม รายละเอียดฉบับเต็มและ validation boundary
อยู่ใน [product definition](./product-definition.md)

ห้ามสร้างตัวเลขผู้ใช้ รีวิว รางวัล พาร์ตเนอร์ ความพร้อมใช้งาน หรือคำกล่าวอ้างด้านความปลอดภัยขึ้นเอง

## 7. Voice and Tone

### Voice

- Friendly
- Clear
- Encouraging
- Helpful
- Straightforward
- Calmly confident

### Writing rules

- ใช้ประโยคสั้น อ่านแล้วเข้าใจทันที
- พูดกับผู้ใช้เหมือนเพื่อนร่วมทริปที่เตรียมตัวมาดี
- เน้นผลลัพธ์ของผู้ใช้ มากกว่ารายการฟีเจอร์เชิงเทคนิค
- ใช้คำที่เชื่อมโยงกับการทำสิ่งต่าง ๆ ร่วมกัน เช่น together, shared, ready, plan, explore
- สร้างความมั่นใจโดยอธิบายสิ่งที่ทำได้จริง

### Avoid

- Corporate jargon
- Overly technical language
- Excessive enthusiasm
- Fear-based messaging
- คำอวดอ้างเกินจริง เช่น “the world’s best” โดยไม่มีหลักฐาน
- น้ำเสียงเอ็กซ์ตรีมหรือเร่งเร้าจนขัดกับความสงบของแบรนด์

### Approved tagline

**Adventure Together.**

### Provisional campaign line

ข้อความนี้เป็นแนวทางสำหรับการออกแบบเนื้อหา ยังไม่ถือว่าอนุมัติ:

**Plan together. Prepare together. Stay ready.**

## 8. Color System

### Core colors

| Token           |       Hex | Intended use                                     |
| --------------- | --------: | ------------------------------------------------ |
| Trail Sage      | `#778873` | Logo, primary CTA, path motif, active states     |
| Meadow Sage     | `#A1BC98` | Hover, supporting surfaces, icons, gentle depth  |
| Trail Sand      | `#DCCFC0` | Cards, borders, soft fields, supporting surfaces |
| Warm Cream      | `#FDF6ED` | Main canvas, light surfaces, text on dark        |
| Brand Dark      | `#1F1F1F` | Headings, primary text, dark surfaces            |
| Background Dark | `#171717` | Dark sections and dark mode backgrounds          |

```css
:root {
  --brand-primary: #778873;
  --brand-secondary: #a1bc98;
  --brand-sand: #dccfc0;
  --brand-cream: #fdf6ed;
  --brand-dark: #1f1f1f;
  --background-dark: #171717;
  --foreground-light: #fdf6ed;
  --surface: #fdf6ed;
  --surface-muted: #dccfc0;
}
```

### Color behavior

- Trail Sage คือจุดโฟกัส ไม่ใช่สีที่ต้องเติมเต็มทุกพื้นที่
- Warm Cream เป็น canvas หลัก และ Trail Sand/Meadow Sage ใช้สร้างชั้นของ surface
- พื้นที่เข้มยังใช้ Brand Dark เพื่อรักษาคอนทราสต์และจังหวะของหน้า
- คอนทราสต์ของข้อความและปุ่มต้องผ่านเกณฑ์ accessibility
- Gradient ใช้อย่างจำกัดเพื่อสร้างมิติ ไม่ใช้เป็นเอฟเฟกต์หลักทั่วทั้งหน้า
- ห้ามยืมสีม่วง โลโก้ หรือ visual signature ของ Phantom มาเป็นอัตลักษณ์ของ Accomp

## 9. Typography

### English body and UI typeface: Nunito Variable

Weights: 400, 500, 700, 800

ใช้กับเนื้อหาและ UI ภาษาอังกฤษ:

- Long-form copy
- Supporting descriptions
- Navigation
- Buttons and UI labels
- FAQ
- Legal and metadata

### Thai body and UI typeface: LINE Seed Sans TH

Weights: Regular 400, Bold 700, ExtraBold 800

ใช้กับเนื้อหา เมนู ปุ่ม FAQ ข้อความกำกับ และ UI ภาษาไทย โดย self-host ไฟล์
WOFF2 จากชุดทางการ `LINE_Seed_Sans_TH_V1.003` เพื่อให้รูปทรงภาษาไทยโค้งมน
เป็นมิตร และแสดงผลสม่ำเสมอบนอุปกรณ์ต่าง ๆ

### Accent typeface: PG Miss Half

Weight: Regular 400

เว็บไซต์ใช้ไฟล์อนุพันธ์ภายในชื่อ **Accomp Thai Accent** ซึ่งแก้ตำแหน่งไม้โท
เฉพาะรูปแบบที่ไม่ซ้อนสระ โดยเก็บไฟล์ PG Miss Half ต้นฉบับไว้สำหรับ rollback

ใช้เฉพาะข้อความที่ทำหน้าที่เป็นจุดเด่น:

- ชื่อแบรนด์ `Accomp` ข้างโลโก้บน Topbar ทั้งภาษาไทยและอังกฤษ
- Hero headline
- Section headings
- Card titles

Hero tagline/eyebrow ต้องใช้ฟอนต์และรูปแบบเดียวกับ Hero body copy:
**“Your companion for every adventure”** ใช้ Nunito และ
**“เพื่อนร่วมทางของทุกการผจญภัย”** ใช้ LINE Seed Sans TH ห้ามใช้ PG Miss
Half กับ navigation, buttons, FAQ, legal body copy หรือข้อความ UI ทั่วไป
สิทธิ์สำหรับการฝังฟอนต์บนเว็บต้องได้รับการยืนยันก่อนเผยแพร่ production

### Typography behavior

- เว็บไซต์ต้อง self-host Nunito Variable, LINE Seed Sans TH และฟอนต์ accent
  ที่ได้รับอนุมัติ เพื่อให้แสดงผลสม่ำเสมอทุกเครื่อง
- ใช้ Nunito Variable กับข้อความภาษาอังกฤษ ใช้ LINE Seed Sans TH
  กับเนื้อหาและ UI ภาษาไทย และใช้ PG Miss Half เฉพาะจุดเด่นของทั้งสองภาษา
  ตามขอบเขตที่กำหนด
- ใช้ tracking `0.02em` กับ PG Miss Half เพื่อให้ตัวอักษรไม่ชิดกันเกินไป
  เมื่อแสดงผลด้วยน้ำหนัก `700–800`
- ใช้น้ำหนัก `800` กับ Hero และหัวข้อ Section, `700` กับชื่อการ์ดและข้อความเด่น
  และคง `400–500` สำหรับเนื้อหาที่ต้องอ่านต่อเนื่อง
- หัวข้อใหญ่ กระชับ และมีพื้นที่หายใจ
- เนื้อหาต้องอ่านง่ายบนหน้าจอกลางแจ้ง
- ไม่ใช้หลายขนาดหรือหลาย weight โดยไม่มีลำดับชั้น
- รักษาความยาวบรรทัดของ body copy ให้อ่านสบาย

## 10. Visual Language

Accomp ต้องดูสะอาด กว้าง สงบ ทันสมัย และสื่อถึงธรรมชาติโดยไม่ตกอยู่ในภาพจำแบบ outdoor ทั่วไป

### Characteristics

- Rounded corners
- Soft shadows
- Large spacing
- Minimal borders
- Smooth transitions
- High readability
- Flat interfaces with subtle depth
- Clear visual hierarchy

### Accomp visual motifs

- เส้นทางที่เคลื่อนไปร่วมกัน
- เส้นชั้นความสูงแบบนามธรรม
- จุดหรือเส้นที่มาบรรจบกัน
- Shared checklist states
- Layered trip cards
- Offline map tiles
- Phone UI mockups
- มิตรภาพและการเตรียมตัวจริงในธรรมชาติ

motif เหล่านี้ต้องเป็นงานต้นฉบับของ Accomp ไม่คัดลอก illustration หรือ asset จากเว็บไซต์อ้างอิง

## 11. Logo Direction

โลโก้ควรสื่อ “companionship through movement” ผ่านต้นสนทรงออร์แกนิกที่เรียบง่าย มากกว่าการใช้ภาพภูเขาหรือสถานที่แบบตรงตัว

### Preferred

- Rounded geometry
- Smooth curves
- Minimal silhouette
- Recognizable at small sizes
- Works in monochrome
- Suitable for an app icon
- ต้นสนต้องมี silhouette ที่เป็นเอกลักษณ์ ไม่ใช่ clip-art outdoor ทั่วไป
- ช่องว่างระหว่างกิ่งสื่อ shared path, connection และการเดินทางร่วมกัน

### Avoid

- Mountains inside circles
- Pine tree ที่สมจริง ซับซ้อน หรือเป็นทรงสามเหลี่ยมสำเร็จรูป
- Generic location pins
- Complex landscapes
- Overly realistic graphics

### Current status

มี [pine symbol exploration v1](./accomp-pine-icon.svg) สำหรับใช้เป็น
องค์ประกอบประกอบฉาก และใช้ภาพมาสคอตต้นสนที่เจ้าของโปรเจกต์ส่งให้เป็น temporary
logo ใน header, footer, legal navigation, 404 และ favicon ก่อน ภาพนี้ยังไม่ใช่
final logo หรือ app icon และต้องเปลี่ยนเมื่อเจ้าของโปรเจกต์ยืนยันแนวทางใหม่

## 12. Iconography

- Rounded
- Simple
- 2px stroke
- Consistent proportions
- Easily recognizable

หัวข้อที่เหมาะสม:

- Trails
- Forest
- Backpack
- Camp
- Compass
- Offline maps
- Friends
- Checklists

ไอคอนทุกชิ้นต้องมาจากชุดเดียวกันหรือวาดตามระบบเดียวกัน และต้องตรวจ license ก่อนใช้จริง

## 13. Illustration

### Direction

- Friendly
- Minimal
- Geometric
- Soft
- Nature-inspired

### Avoid

- Cartoon exaggeration
- Excessive gradients
- Overly detailed artwork
- ภาพที่ทำให้แบรนด์ดูเด็กเกินไป

## 14. Photography

### Emphasize

- Real people and genuine friendships
- Forests, mountains and campsites
- Hiking equipment in actual use
- Natural lighting
- Candid moments of planning and moving together

### Avoid

- Artificial studio lighting
- Heavy editing
- Oversaturated colors
- ภาพคนยืนโพสที่ไม่สื่อการร่วมมือหรือการเดินทางจริง

รูปทุกภาพต้องมีสิทธิ์ใช้งานเชิงพาณิชย์และมีข้อมูล attribution ตามที่ license กำหนด

## 15. Motion Principles

- Calm
- Purposeful
- Lightweight
- Smooth transitions
- Gentle scaling
- Soft fades
- Fluid loading behavior

### Avoid

- Bouncy motion
- Aggressive effects
- Long animations
- Motion ที่ขัดขวางการอ่านหรือทำให้ CTA เคลื่อนหนีผู้ใช้

เว็บไซต์ต้องรองรับ `prefers-reduced-motion` และยังสื่อสารเนื้อหาได้ครบเมื่อปิด animation

## 16. UI Principles

- Prioritize readability
- Minimize cognitive load
- Keep actions obvious
- Reduce unnecessary steps
- Design for outdoor visibility
- Support one-handed mobile use
- Offline-first whenever applicable to the product story

เว็บไซต์โปรโมตไม่ใช่ตัวแอป จึงใช้หลักการเหล่านี้กับ navigation, CTA, carousel และการอ่านเนื้อหา โดยไม่สร้าง product interface ที่ใช้งานจริง

## 17. Website Expression

เว็บไซต์ควรให้ความรู้สึกในระดับเดียวกับ reference ด้าน:

- การเล่าเรื่องแบบเป็นบท
- หัวข้อขนาดใหญ่
- พื้นที่ว่างที่ตั้งใจใช้
- Hero ที่มี visual impact
- Feature cards ที่สำรวจได้
- Sticky navigation
- การสลับ light/dark section
- Final download CTA ที่ชัดเจน

แต่ต้องแตกต่างจาก reference ด้วย:

- สีและ typography ของ Accomp
- เนื้อหา outdoor trip planning
- ภาพคนและธรรมชาติ
- topographic/path motifs
- app UI mockups ของ Accomp
- motion ที่สงบกว่าและสอดคล้องกับความน่าเชื่อถือ

## 18. Brand Guardrails

- ห้ามคัดลอกข้อความ รูปภาพ วิดีโอ โลโก้ ไอคอน illustration source code หรือ animation asset ของ Phantom
- ห้ามสร้างหน้า clone แบบ pixel-for-pixel ที่ทำให้ผู้ใช้เข้าใจผิดว่าเกี่ยวข้องกับ Phantom
- ใช้ reference เพื่อกำหนดระดับงาน จังหวะ และ interaction pattern เท่านั้น
- ทุกคำกล่าวอ้างเกี่ยวกับแอปต้องได้รับการยืนยันก่อนเผยแพร่
- ทุก asset ต้องเป็นของ Accomp, สร้างใหม่, หรือมี license ที่เหมาะสม
- Brand identity นี้ครอบคลุมเว็บไซต์โปรโมตเท่านั้นในสโคปปัจจุบัน

## 19. Pending Brand Decisions

ต้องได้รับคำตอบหรือการอนุมัติก่อนเริ่มงาน visual final:

- Logo symbol และ wordmark
- App icon
- ภาษาหลักของเว็บไซต์: English, Thai หรือ bilingual
- ภาพถ่ายจริง, stock, AI-generated หรือการผสมกัน
- Screenshots/mockups ของแอปที่อนุญาตให้นำมาโปรโมต
- App Store และ Google Play availability
- CTA ก่อนแอปเปิดตัว: Download, Join waitlist หรือ Get notified
- Social proof ที่ตรวจสอบได้
- Legal entity, contact, privacy policy และ terms
